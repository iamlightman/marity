# Project Rules: Marity Luxury Fragrance App

- **Workspace Scope**: This project is the **Marity** mobile fragrance application.
- **Strict Brand Isolation**: Do not use "Jectylines" or any details from legacy/other projects. Use the project's own authorized branding (**Marity** / **Marity Fragrances** / **Maison Marity**).
- **Design Standard**: Clean liquid metallic glass, authentic luxury retail layouts, no artificial phone mockups, no sound effects, no dynamic island gimmicks.
